연수 안내

Claude로 수업 준비와 업무를 돕고, Claude Code로 우리 반에 꼭 맞는 수업 도구를 직접 만들어 보는 교원 연수 자료입니다. 심화 과정에서는 오프라인 수행평가 기록 도구와 구글 스프레드시트 자동화까지 다룹니다. 코딩을 해 본 적이 없어도 순서대로 따라 할 수 있게 구성했습니다.

Claude Code 설치 방법과 이용 조건은 2026년 9월 공식 문서를 확인해 정리했습니다. 요금제, 모델 이름, 화면 구성은 자주 바뀌므로 연수 전에 부록의 공식 링크로 한 번 더 확인해 주세요.

연수 목표

  • Claude를 쓸 수 있는 곳과 요금제, 안전 수칙을 이해하고 수업과 업무에 맞게 요청할 수 있다.
  • 바이브 코딩의 뜻을 이해하고, 설치 없이 채팅만으로 간단한 수업 도구를 만들 수 있다.
  • Claude Code에서 계획, 구현, 확인, 수정의 흐름으로 수업용 웹 도구를 완성하고 안전하게 공유할 수 있다.
  • 심화: 인터넷 없이 쓰는 수행평가 기록 도구를 만들고, Apps Script로 학생 활동 기록을 자동으로 정리해 확인할 수 있다.

1교시

1교시. Claude와 첫 만남

강의 25분

학습 목표

  • Claude가 어떤 도구이고 어디에서 쓸 수 있는지 설명할 수 있다.
  • 생성형 AI가 잘하는 일과 조심해야 할 일을 구분할 수 있다.
  • 계정을 만들고 첫 대화를 시작할 수 있다.

Claude는 어떤 도구인가요

Claude는 미국 AI 기업 Anthropic이 만든 AI 어시스턴트입니다. 사람에게 부탁하듯 문장으로 요청하면 글을 쓰고, 긴 자료를 요약하고, 표를 정리하고, 코드를 짭니다. 검색창에 낱말 몇 개를 넣을 때와 달리 누구를 위해, 무엇을, 어떤 모양으로 원하는지 자세히 말할수록 결과가 좋아집니다.

검색은 이미 있는 답을 찾아 주고, Claude는 내 상황에 맞는 초안을 새로 만들어 줍니다. 그래서 초안을 검토하고 고치는 일은 여전히 선생님 몫입니다.

웹 claude.ai설치 없이 바로 대화하고, 파일을 올리고, 결과물을 옆 창에서 확인1~3교시

쓸 수 있는 곳은 요금제와 시기에 따라 다릅니다. 이 연수에서는 웹과 Claude Code만 다룹니다.

요금제는 어떻게 다른가요

무료 플랜으로도 대화, 파일 올리기, 간단한 결과물 만들기를 충분히 해 볼 수 있습니다. 더 많이 쓰거나 Claude Code를 쓰려면 Pro, Max 같은 개인 유료 플랜이나 Team, Enterprise 같은 기관용 플랜이 필요합니다. 가격과 사용 한도는 자주 바뀌므로 연수 당일 claude.ai의 요금제 화면을 함께 보며 확인하세요.

기관 도입학교나 교육청 단위로 쓰려면 개인 결제보다 기관용 플랜의 계약 조건과 데이터 처리 방식을 먼저 검토하는 것이 좋습니다.

잘하는 일, 조심할 일

잘하는 일

  • 초안 쓰기: 가정통신문, 수업 안내문, 활동지 문항
  • 수준 바꾸기: 같은 내용을 초등 3학년 눈높이로, 또는 전문 용어로
  • 정리하기: 긴 회의 자료를 요점과 표로
  • 아이디어 내기: 수업 도입 활동, 모둠 과제 주제
  • 코드 짜기: 타이머, 뽑기, 퀴즈 같은 작은 웹 도구

조심할 일

  • 그럴듯한 오류: 없는 자료나 틀린 사실을 자신 있게 말할 수 있습니다. 이를 환각이라고 부릅니다.
  • 최신 정보: 학습 시점 이후의 소식은 웹 검색을 켜야 반영됩니다.
  • 정답과 계산: 정답표, 풀이, 채점 기준은 사람이 반드시 확인합니다.
  • 개인정보: 학생 이름, 성적, 상담 내용은 입력하지 않습니다.
  • 판단의 책임: 평가와 생활지도 결정은 교사가 내립니다.

계정 만들고 첫 대화 보내기

  1. claude.ai에 접속합니다

    브라우저 주소창에 claude.ai를 입력합니다. 휴대폰이라면 앱 스토어에서 Claude를 검색하고, 만든 회사가 Anthropic인지 확인한 뒤 설치합니다.

  2. 가입하고 로그인합니다

    Google 계정이나 이메일 주소로 가입합니다. 이메일로 가입했다면 받은 편지함에 온 안내를 따라 로그인합니다. Claude 계정은 만 18세 이상만 만들고 쓸 수 있습니다.

  3. 첫 대화를 보냅니다

    입력창에 아래 문장을 붙여넣고, 형광펜 부분을 선생님 상황에 맞게 바꿔 보냅니다.

  4. 이어서 요청합니다

    답을 받으면 "3번을 더 자세히 알려 주세요"처럼 대화를 이어 갑니다. 주제가 바뀌면 새 대화를 여는 편이 결과가 깔끔합니다.

강사 도움말이 교시의 목표는 모든 참여자가 첫 요청을 직접 보내 보는 것입니다. 계정이 아직 없는 분은 옆 사람 화면을 함께 보고, 쉬는 시간에 가입을 마치도록 안내하세요.

바이브 코딩이란

바이브 코딩은 코드를 한 줄씩 직접 쓰는 대신, 만들고 싶은 것을 말로 설명하고 AI가 만든 결과를 실행해 보며 고쳐 나가는 방식입니다. 2025년 초 AI 연구자 안드레이 카파시(Andrej Karpathy)가 쓴 표현이 널리 퍼졌습니다. 코드를 읽지 못해도 시작할 수 있지만, 결과가 의도대로 동작하는지 따져 보는 눈은 꼭 필요합니다.

선생님이 할 일은 코드를 쓰는 것이 아니라, 무엇이 필요한지 분명히 말하고 결과를 학생의 눈으로 점검하는 것입니다. 수업을 설계하고 다듬는 일과 크게 다르지 않습니다.

세 가지를 반복합니다

  • 말하기. 누가, 어디서, 무엇을 하려는 도구인지와 꼭 필요한 기능을 설명합니다.
  • 확인하기. 결과물을 직접 눌러 보고, 학생이 쓴다고 생각하며 이것저것 해 봅니다.
  • 고치기. 무엇을 했더니 어떻게 됐고 원래는 어떻게 되어야 하는지 말합니다. 그리고 다시 확인합니다.

실습: 모둠 뽑기 도구 만들기

claude.ai에서 새 대화를 열고 아래 요청을 보냅니다. 화면 오른쪽(휴대폰은 아래)에 결과물 창이 열리고 도구가 나타나면 성공입니다. 결과물 창이 열리지 않으면 "아티팩트로 만들어 주세요"라고 덧붙이세요.

개인정보학생 실명 명단은 대화창에 붙여넣지 마세요. 도구를 만드는 데 이름은 필요 없습니다. 실습에서는 완성된 도구에 1번, 2번 같은 번호를 넣어 확인합니다.

채팅으로 만든 도구의 한계

채팅에서 만든 도구는 아이디어를 빠르게 시험해 보기에 좋습니다. 결과물을 링크로 공유하거나 파일로 내려받을 수도 있지만, 제공 방식은 요금제와 설정에 따라 다릅니다. 도구가 커질수록 긴 코드를 대화 안에서 계속 고치기 번거로워지고, 여러 파일로 나누어 보관하기도 어렵습니다. 이때 내 컴퓨터 폴더에서 파일을 직접 만들고 고치는 Claude Code가 필요합니다.

4교시. Claude Code 설치와 첫 세션

채팅과 무엇이 다른가요

비교채팅 (claude.ai)Claude Code
결과물이 생기는 곳대화 옆 결과물 창내 컴퓨터 폴더 안의 실제 파일
고치는 방식대화 안에서 결과물을 고쳐 다시 보여 줌필요한 파일의 필요한 부분만 수정

안전장치대화 안에서만 동작파일을 바꾸거나 명령을 실행하기 전에 허락을 구함
필요한 것브라우저, 무료 계정도 가능설치, 유료 플랜 또는 Console 계정

채팅이 옆에서 조언해 주는 동료라면, Claude Code는 내 컴퓨터 앞에 앉아 직접 작업하는 보조 교사에 가깝습니다. 그래서 어느 폴더에서 일을 맡기는지, 무엇을 허락하는지가 중요합니다.

준비물

  • Pro, Max, Team, Enterprise 플랜 계정 또는 Claude Console 계정. 무료 플랜으로는 Claude Code를 쓸 수 없습니다.
  • macOS 13 이상 또는 Windows 10(1809) 이상, 메모리 4GB 이상인 컴퓨터와 인터넷 연결
  • 프로그램 설치 권한. 관리자 권한은 필요 없지만, 학교 PC는 보안 프로그램 때문에 막힐 수 있으니 미리 확인합니다.

터미널이 부담스럽다면Claude 데스크톱 앱에서도 터미널 없이 Claude Code를 쓸 수 있습니다. 이 자료는 macOS와 Windows에서 같은 순서로 따라 할 수 있는 터미널 방식으로 설명하고, 데스크톱 앱 사용법은 부록의 공식 안내 링크로 대신합니다.

터미널 열기

터미널은 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 이 연수에서는 명령어를 외울 필요 없이 복사해 붙여넣고 Enter만 누르면 됩니다.

설치하기

macOS

터미널에 아래 명령을 붙여넣고 Enter를 누릅니다. 설치가 끝나면 터미널 창을 닫고 새로 엽니다.

Windows

PowerShell에 아래 명령을 붙여넣고 Enter를 누릅니다. 관리자 권한으로 열 필요는 없습니다. 설치가 끝나면 PowerShell 창을 닫고 새로 엽니다.

줄 앞에 PS가 보이면 PowerShell이 맞습니다. Git for Windows는 선택 사항입니다. 없으면 Claude Code가 PowerShell로 명령을 실행하므로 이 연수에서는 설치하지 않아도 됩니다.

다른 방법

평소 패키지 관리자를 쓰는 분은 아래 방법으로도 설치할 수 있습니다. 이 방식은 자동으로 업데이트되지 않으므로 가끔 직접 업데이트해야 합니다.

설치가 잘 됐는지 확인합니다. 버전 번호가 나오면 성공입니다.

명령어 출처설치 명령은 바뀔 수 있습니다. 연수 전날 부록의 공식 설치 안내에서 한 번 더 확인하고, 출처가 분명하지 않은 블로그나 영상 속 설치 명령은 실행하지 마세요.

첫 세션 시작하기

  1. 연습 폴더를 만들고 들어갑니다

    중요한 파일이 없는 빈 폴더에서 시작해야 안전합니다. 아래 명령은 사용자 폴더 안에 quiz-app 폴더를 만들고 그 안으로 들어갑니다. macOS와 Windows에서 똑같이 쓸 수 있습니다.

    이 폴더를 파인더나 파일 탐색기 창으로 보고 싶으면 macOS는 open ., Windows는 explorer .를 입력합니다.

  2. Claude Code를 실행합니다

    처음 실행하면 화면 테마 고르기와 로그인 안내가 차례로 나옵니다. 방향키로 고르고 Enter를 누릅니다. 로그인 방식에서 요금제 계정을 고르면 브라우저가 열리고, 승인하면 터미널로 돌아옵니다. 순서와 문구는 버전에 따라 조금 다를 수 있습니다.

  3. 이 폴더를 믿을지 답합니다

    이 폴더의 파일로 작업해도 되는지 묻는 질문이 나옵니다. 방금 만든 연습 폴더이므로 허용합니다. 내 문서 폴더 전체나 바탕화면처럼 중요한 파일이 섞인 곳에서 이 질문이 나왔다면 여기서 멈추고 연습 폴더로 옮기세요.

  4. 첫 요청을 보냅니다

  5. 권한 요청을 읽고 허락합니다

    Claude는 파일을 만들기 전에 어떤 파일에 무엇을 쓸지 보여 주고 허락을 구합니다. 파일 이름과 내용을 훑어보고 Yes를 고릅니다. 거절하려면 Esc를 누릅니다. 이번 세션 동안 계속 허락하는 선택지도 있지만, 처음에는 한 번씩 확인하는 습관을 들이세요.

  6. 결과를 확인합니다

    연습 폴더를 열고 hello.html을 더블클릭하면 브라우저에서 열립니다. 버튼을 눌러 보고, 고칠 점이 있으면 터미널에 말로 적어 보냅니다. "hello.html을 브라우저로 열어 주세요"라고 부탁해도 되는데, 이때는 명령을 실행해도 되는지 묻습니다.

  7. 끝내고, 다음에 이어 갑니다

    /exit를 입력하면 끝납니다. 나중에 같은 폴더에서 claude --continue를 입력하면 직전 대화를 이어 갈 수 있습니다.

1. 기획 메모 쓰기

코드를 부탁하기 전에 메모장에 네 줄을 적습니다. 이 메모가 그대로 좋은 요청이 됩니다.

이번에는 안 할 것을 적어 두면 기능이 욕심껏 붙어 앱이 복잡해지는 것을 막을 수 있습니다. 작게 완성한 뒤 하나씩 더하는 편이 훨씬 빠릅니다.

2. CLAUDE.md에 규칙 적기

CLAUDE.md는 Claude Code가 이 폴더에서 작업을 시작할 때마다 먼저 읽는 메모 파일입니다. 매번 말하기 번거로운 규칙을 적어 두면 새 대화를 시작해도 지켜집니다. 아래 요청을 Claude Code 입력창에 붙여넣어 보내면 파일을 만들어 줍니다. 여러 줄도 한 번에 붙여넣을 수 있습니다.

규칙은 언제든 고칠 수 있습니다. 이미 코드가 있는 폴더라면 /init 명령으로 폴더를 분석해 CLAUDE.md 초안을 자동으로 만들 수도 있습니다.

3. 계획부터 세우게 하기

Shift+Tab을 몇 번 눌러 화면 아래에 계획 모드 표시가 나타나면 아래 요청을 보냅니다.

계획을 읽고 바꾸고 싶은 점은 이 단계에서 말합니다. "해설은 맞혔을 때도 보여 주세요", "보기 순서는 풀 때마다 섞어 주세요"처럼요.

4. 첫 버전 만들기

계획이 마음에 들면 진행할지 묻는 선택지에서 승인합니다. 파일 수정은 한 번씩 확인하는 방식을 고르세요. 선택지 없이 계획 모드를 빠져나왔다면 아래처럼 요청합니다.

권한 요청이 나오면 만들려는 파일 이름이 계획과 같은지 보고 허락합니다. 작업이 끝나면 폴더에 index.html, questions.js 같은 파일이 생깁니다. 파일 이름은 계획에 따라 조금 다를 수 있습니다.

5. 학생 입장에서 확인하기

확인은 코드를 몰라도 할 수 있고, 반드시 사람이 해야 하는 일입니다. 브라우저에서 앱을 열고 하나씩 점검하세요. 체크한 항목은 이 브라우저에만 저장됩니다.

정답 확인AI가 만든 문항은 정답이나 해설이 틀릴 수 있습니다. 학생에게 쓰기 전에 questions.js의 문제를 교사가 한 번씩 직접 풀어 보세요.

자주 막히는 곳

claude를 입력했더니 명령을 찾을 수 없다고 나와요

설치 직후에는 터미널이 새 명령을 모를 수 있습니다. 터미널 창을 완전히 닫고 새로 연 뒤 다시 입력하세요. 그래도 안 되면 설치 명령을 한 번 더 실행하고, 설치가 끝날 때 화면에 나오는 안내를 끝까지 읽어 보세요. claude가 실행된다면 claude doctor로 설치 상태를 점검할 수 있습니다.

Windows에서 설치 명령이 오류를 내요

irm을 인식할 수 없다고 나오면 PowerShell이 아니라 명령 프롬프트(CMD)를 연 것입니다. 시작 메뉴에서 PowerShell을 찾아 다시 여세요. 학교망에서 접속이 막혀 오류가 난다면 정보 담당자에게 claude.ai 관련 주소를 허용해 달라고 요청하세요.

로그인 창이 열리지 않거나 다른 계정으로 들어갔어요

브라우저가 저절로 열리지 않으면 터미널에 표시된 주소를 복사해 브라우저에 붙여넣으세요. 계정을 바꾸려면 Claude Code 안에서 /login을 입력합니다.

사용량 한도에 도달했다고 나와요

요금제마다 일정 시간 동안 쓸 수 있는 양이 정해져 있습니다. 창을 열어 두면 한도가 풀린 뒤 하던 작업을 자동으로 이어 가고, 기다리지 않으려면 Esc로 취소할 수 있습니다. 대화가 길수록 사용량이 빨리 늘어나므로 작업이 바뀔 때마다 /clear로 새로 시작하세요.

하나를 고쳐 달라고 했더니 다른 기능이 망가졌어요

입력창이 빈 상태에서 Esc를 두 번 눌러 되돌리기 메뉴를 열고, 망가지기 전 시점을 고르세요. 그다음 "다른 기능은 건드리지 말고 이것만 고쳐 주세요"처럼 범위를 좁혀 다시 요청합니다.

같은 실수를 계속 되풀이해요

대화가 길어지면 앞에서 한 지시가 흐려질 수 있습니다. 지금까지 된 것과 안 된 것, 원하는 결과를 세 줄로 정리한 뒤 /clear로 새 대화를 열어 다시 설명하세요. 계속 지켜야 할 규칙이라면 CLAUDE.md에 적어 둡니다.

브라우저에 하얀 화면만 나와요

코드 오류로 화면이 그려지지 않은 경우가 많습니다. 브라우저 개발자 도구를 열고(Windows는 F12, macOS는 ⌥+⌘+I) Console 탭에 나온 빨간 오류 문장을 복사해, "index.html을 열면 하얀 화면만 나오고 콘솔에 이런 오류가 있어요"라고 보여 주세요.

한글이 깨져 보여요

"모든 파일을 UTF-8로 저장하고, HTML에 문자 인코딩 설정을 넣어 주세요"라고 요청하세요.

답이 영어로 나와요

"앞으로 한국어로 답해 주세요"라고 말하거나, CLAUDE.md에 "답변은 한국어로"라고 적어 둡니다.

권한 요청이 너무 자주 나와 번거로워요

연습 폴더에서 파일 수정만 되풀이된다면 Shift+Tab으로 파일 수정 자동 허락 모드를 쓸 수 있습니다. 명령 실행이나 다른 폴더에 접근하려는 요청은 계속 읽고 판단하세요. 모든 확인을 건너뛰는 옵션은 쓰지 않습니다.

오래 함께 일하는 다섯 가지 습관

  • 작게 시작하기. 기능 세 개짜리를 먼저 완성하고 하나씩 더합니다.
  • 한 번에 하나씩. 여러 가지를 한꺼번에 부탁하면 무엇이 문제를 일으켰는지 찾기 어렵습니다.

  • 잘 되면 저장. 동작하는 버전은 폴더를 복사해 두거나 git으로 저장합니다.
  • 결과는 사람이 확인. 코드는 읽지 못해도 동작, 내용, 정답은 반드시 직접 봅니다.

대화 정리/clear는 대화를 비우고 새로 시작합니다. 이전 대화는 지워지지 않아 나중에 다시 불러올 수 있습니다. /compact는 지금까지의 대화를 요약해 짧게 줄인 뒤 이어 갑니다. 작업 주제가 바뀌면 /clear, 같은 작업인데 대화가 길어졌다면 /compact를 쓰세요.

교사가 지킬 일곱 가지 수칙

  1. 학생 개인정보는 넣지 않습니다. 이름, 성적, 상담과 건강 정보, 연락처, 얼굴 사진은 대화에도 파일에도 넣지 않습니다. 꼭 필요하면 번호나 가명으로 바꿉니다.
  2. 학생이 Claude를 직접 쓰게 하지 않습니다. Claude 계정은 만 18세 이상만 만들고 쓸 수 있습니다. 교사 계정을 학생에게 빌려주는 일도 피하고, 학생에게는 교사가 만든 결과물을 쓰게 합니다. 오늘 만든 퀴즈 앱은 Claude에 접속하지 않으므로 학생이 써도 됩니다.
  3. 결과물은 교사가 검증합니다. 사실, 정답, 맞춤법, 편향된 표현을 확인한 뒤 학생에게 제공합니다.

  5. 저작권을 지킵니다. 교과서 본문, 문제집 문항, 인터넷에서 찾은 그림과 음원을 그대로 넣어 배포하지 않습니다. 직접 만든 문항과 이용이 허락된 자료를 씁니다.
  6. 개인정보 설정을 확인합니다. 개인 플랜은 설정의 개인정보 항목에서 대화 내용을 AI 모델 개선에 활용할지 고를 수 있습니다. 업무 자료를 다룬다면 이 설정과 기관용 플랜 여부를 함께 살펴보세요.
  7. 학교와 교육청 지침이 먼저입니다. 생성형 AI 활용 지침, 정보 보안 규정, 개인정보 보호 규정을 먼저 확인합니다.

파트 1. 오프라인 수행평가 기록 도구

체육관, 과학실, 운동장처럼 무선망이 약한 곳에서도 수행평가는 진행됩니다. 파일 하나를 열어 쓰고 기록이 기기 밖으로 나가지 않는 도구라면 망 상태와 개인정보 걱정을 함께 줄일 수 있습니다. 5교시의 퀴즈 앱과 같은 방식으로, 이번에는 교사가 손에 들고 쓰는 기록판을 만듭니다.

평가 요소는 2교시 요청문 도우미로 만든 채점 기준표를 그대로 옮겨 오세요. 기준과 도구가 따로 놀지 않게 됩니다.

계획을 확인하고 만들게 한 다음, 반드시 혼자 먼저 써 봅니다. 수업 중에 처음 써 보면 고칠 시간이 없습니다.

파트 2. Apps Script로 학생 활동 기록 확인하기

Apps Script는 구글 스프레드시트, 설문지, 문서에 붙여 쓰는 자동화 도구입니다. 구글 계정만 있으면 되고 따로 설치할 것이 없어서, 4교시의 설치 과정을 건너뛰고도 자동화를 맛볼 수 있습니다. 코드는 Claude에게 부탁해 받아서 붙여넣습니다.

가장 흔한 흐름은 이렇습니다. 학생이 구글 설문지로 과제나 자기평가를 제출하면 응답이 스프레드시트에 쌓이고, Apps Script가 그 시트를 읽어 제출 현황과 미제출 번호를 정리해 줍니다. 명단과 응답을 눈으로 대조하던 일이 버튼 하나로 바뀝니다.

  1. 응답을 모을 시트를 준비합니다

    구글 설문지의 응답 탭에서 스프레드시트에 연결합니다. 설문 문항은 이름 대신 번호나 학번을 받도록 만들고, 명단 시트에는 우리 반 번호를 미리 적어 둡니다.

  2. Apps Script 편집기를 엽니다

    스프레드시트 상단 메뉴에서 확장 프로그램 > Apps Script를 고르면 새 탭에 코드 편집기가 열립니다. 이렇게 만든 스크립트는 그 스프레드시트에만 붙어 있습니다.

  3. 실제 자료 대신 구조만 알려 주고 코드를 받습니다

    Claude에는 시트 이름과 열 제목, 가짜 예시 한 줄만 보냅니다. 실제 응답을 통째로 붙여넣지 않습니다.

  4. 코드를 붙여넣고 실행합니다

    편집기에 있던 기본 코드를 지우고 받은 코드를 붙여넣은 뒤 저장합니다. 처음 실행하면 내 계정으로 이 스프레드시트에 접근해도 되는지 묻는 승인 창이 나옵니다. 내가 직접 만든 스크립트일 때만 승인하고, 남이 보낸 스크립트는 승인하지 마세요.

    스프레드시트 상단에 "수업 도우미" 메뉴를 만들어 주는 부분입니다. 외울 필요는 없고, 무슨 일을 하는 코드인지 궁금하면 Claude에게 물어보면 됩니다.

  5. 결과를 확인하고 고칩니다

    제출 현황 시트를 명단과 대조해 봅니다. 틀린 곳이 있으면 3교시의 공식대로 말합니다. 빨간 오류 창이 뜨면 그 문장을 그대로 복사해 보여 주세요. 편집기의 실행 로그에서도 오류를 확인할 수 있습니다.

  6. 자동으로 실행되게 합니다 (선택)

    편집기 왼쪽의 트리거에서 설문이 제출될 때마다, 또는 매일 정해진 시각에 실행되도록 예약할 수 있습니다. "매일 오전 8시에 제출 현황을 새로 만드는 트리거를 어떻게 거는지 단계별로 알려 주세요"라고 물으면 화면 순서를 안내해 줍니다.

학교 계정 확인교육청에서 준 구글 계정은 Apps Script 실행이나 외부 공유가 막혀 있을 수 있습니다. 연수 전에 정보 담당자에게 확인하고, 스프레드시트 공유 범위가 링크 공개로 되어 있지 않은지도 함께 보세요.

사본에서 먼저시트를 지우거나 덮어쓰는 동작이 들어간 스크립트는 사본을 만들어 시험하세요. 파일 > 사본 만들기로 복사한 뒤 마음 놓고 돌려 보면 됩니다.
