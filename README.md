# 말로 만드는 / 말로 만든 수업 도구 — 정보 교사 연수 자료

클로드(Claude Code)로 수업 도구를 만드는 방법과, 그렇게 만든 정보 수업·평가 자료를 소개하는
**정보 교사 연수용 자료 두 편**입니다. 브라우저로 바로 열립니다.

| 자료 | 주소 |
|---|---|
| **사례 소개편** 「말로 만든 수업 도구」 — 정보 수업·평가 자료 30종을 한 쪽씩 소개하는 슬라이드 | https://trmoo.github.io/teacher-training26/ |
| **실습편** 「말로 만드는 수업 도구」 — 클로드 설치부터 수업 도구 만들기까지 따라 하는 8교시 | https://trmoo.github.io/teacher-training26/claude-vibe-coding-teacher-training.html |

## 사례 소개편 쓰는 법
1. `←` `→` 로 넘깁니다. 전자칠판에서는 손가락으로 밀어 넘겨도 됩니다.
2. `M` 목차 · `N` 발표자 메모 · `Z` 화면 크게 · `1`~`4` 탭 · `F` 전체 화면 · `T` 밝게/어둡게.
3. 자료 쪽의 QR 코드를 휴대폰으로 비추면 그 자료가 바로 열립니다.
4. 주소 끝에 `#쪽이름` 을 붙이면 그 쪽이 바로 열립니다.

인터넷 없이 쓰려면 이 저장소를 내려받아 `index.html` 을 더블클릭하세요(`shots/` 폴더를 함께 두어야 화면 캡처가 보입니다).
